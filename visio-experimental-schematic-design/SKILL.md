# Visio Experimental Schematic Design

Use this skill for every Visio experimental schematic or科研流程示意图 design/revision.

## Core Workflow

1. Define a coordinate grid before drawing.
2. Place all node centers, module frames, labels, and arrow turning points on the grid.
3. Build the overall layout as a near-rectangular left-to-right workflow; decide the number of modules from the actual experiment, not from a fixed template.
4. Export an image and visually check overlap, alignment, arrow routing, and color semantics before finishing.

## Alignment

- Use fixed column centers and fixed row centers; avoid freehand placement.
- Keep all module frames with the same top and bottom boundaries when possible.
- Align same-level nodes horizontally; align same-stage nodes vertically.
- Use equal spacing for paired branches, such as Control/Treatment or phenotype/molecular assays.
- Prefer Visio one-piece connectors and one-piece frames so the user can manually adjust them later. Only replace with manual line segments when automatic routing creates obvious overlap or misalignment.
- Keep arrow turning lengths symmetric for corresponding branches.

## Color

- Use color for meaning, not decoration.
- Blue: samples, groups, sampling, assays, measurements.
- Red: intervention, treatment, statistical analysis, result output.
- Black: decision nodes, raw data, arrows, neutral labels, and explanatory text.
- Use the same color for corresponding or same-category content.
- Keep all text black for readability.

## Local And Overall Layout

- Choose module count dynamically from content; diagrams may have 3, 4, 5, or more modules. Do not force a fixed four-part structure.
- Typical modules may include sample/grouping, intervention, measurement, analysis, and output, but merge or split modules according to the experiment.
- Within each module, use simple top/middle/bottom rows or symmetric branches when helpful.
- Paired content, such as Control/Treatment or phenotype/molecular assays, should be arranged symmetrically.
- Overall figure should read left-to-right and have a clean rectangular silhouette.

## Typography And Frames

- Chinese font: 黑体.
- English font: Arial.
- Use black text throughout.
- Use long-dashed external module frames; prefer one-piece frame objects rather than separate line segments, unless Visio constraints make this impractical.
- External frames should indicate grouping only; leave enough inner margin so frames do not touch nodes or arrows, and keep them easy for the user to manually drag/resize.
- Module labels should sit near the frame edge without covering diagram content.

## Validation Checklist

- No text, node, arrow, or frame overlap.
- Module frames are aligned, one-piece when possible, and do not intrude into content.
- Arrow turns are grid-aligned and symmetric where branches correspond.
- Colors match semantic categories.
- The whole diagram appears rectangular and publication-ready.
